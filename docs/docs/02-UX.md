# UX/UI — Finance Chat

# Objetivo

Criar uma experiência extremamente simples para que qualquer pessoa consiga controlar suas finanças apenas conversando.

O usuário nunca deverá sentir que está preenchendo um formulário.

---

# Persona

Idade: 28 anos

- Quer economizar dinheiro;
